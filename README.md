## Reuse and contribute

AIAP original software and schemas use **Apache-2.0**; author-controlled research materials use **CC-BY-4.0**, under its [open-license grant](https://github.com/MathGov/AIAP/blob/main/OPEN_LICENSE_GRANT.md), which supersedes earlier restrictive author notices. Auditable Flourishing uses **CC-BY-4.0**. ORSH / AIU uses CC-BY-4.0 for author-owned research and Apache-2.0 for original software. Check each collection's license scope, attribution requirements and third-party notices.

Start with a project's README, evidence/validation statement and fixed release. Use its issue tracker for precise corrections or reproducible failures and its contribution guide for proposed changes. Publication and passing integrity checks do not establish empirical effectiveness, independent validation, certification or deployment authority. ORSH's numerical findings and AIU's philosophical argument have distinct evidence boundaries.
